## Como executar
1. Instale o .NET 8+ e o MySQL.
2. Crie `appsettings.Development.json` com sua connection string (arquivo ignorado pelo git).
3. Execute o script: `cmd /c "mysql -u root -p < Database\script.sql"`
4. Rode: `dotnet run`
